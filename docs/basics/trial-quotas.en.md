# Trial version and quotas

!!! info "Concept — What the trial version can do, which quantities are limited and how to get to the full version"

The **Trial version** of the desktop app contains the full range of functions,
but is limited in time and in quantities. This lets you try out all
areas realistically before you decide on the full
version.

!!! info "How to get the trial version"
    Since version 2.0, the trial version is a module of the
    [customer account](../setup/account.md): **Herzog CAB Trial** (30 days).
    Herzog creates the account and invites you; you install the
    normal installer and sign the computer in to the account — nothing more is
    needed. The trial version also applies to the
    [web app](../web/index.md), with the same limits. See
    [Trial](../web/trial.md).

## How to recognize the trial version { #woran-sie-die-testversion-erkennen }

On the [home page](home.md), the **Trial version** tile appears directly below the greeting
with:

* a **remaining time badge** ("X days remaining") — orange, at 7 days
  or less red. The trial period runs for 30 days; the badge is green only
  if more than 30 days remain.
* four **counter tiles** showing the usage of the quantity-limited areas
  (e.g. "2 / 3 customers"). A fully used quota is
  shown in red.

## The quotas at a glance { #die-kontingente-im-uberblick }

| Area | Trial version | Full version |
|---|---|---|
| Customers | at most 3 | unlimited |
| Designs | at most 2 | unlimited |
| Machines (braiding and bobbin winding machines together) | at most 2 | unlimited |
| Orders | at most 4 | unlimited |
| User accounts | 1 | unlimited |
| Calculation runs | 100 per calculation type | unlimited |
| Duration | 30 days | Annual subscription, renewable |

## What happens at the limit { #was-an-der-grenze-passiert }

* **Creating objects:** Once a quota is reached, no further
  entry of this type can be saved — not even via detours such as
  duplicating. The message "Trial version: A maximum of
  X … is possible. The full version removes this limit." appears. If you delete
  an existing entry, the quota becomes free again.
* **Calculations:** After each successful run, a short
  notification shows how many remain ("Trial version: X calculations of this type
  remaining"); from five remaining runs on, as a warning. Once the quota of a
  calculation type is used up, **Calculate** is locked on this page
  — other calculation types remain usable. Failed runs and
  reopening from the [history](history.md) do not use up any quota.
* **End of the trial period:** After the 30 days have expired, the program
  can no longer be started with the trial licence.

## The way to the full version { #der-weg-zur-vollversion }

The full version removes all limits; your data created in the trial version
is kept and continues to be used.

1. Order the annual subscription **Herzog CAB**, in the web app under
   [Subscription and ordering](../web/subscription.md) or in the licence portal under
   *Order*. Or contact Herzog; contact details under
   [Support](../help/support.md).
2. As soon as the subscription has been activated, Herzog CAB fetches the full version
   by itself at the next start; *Settings > Licence* then shows
   *Edition: Full version*. With a dongle licence, activate the
   dongle as described under [Signing in and obtaining a licence](../setup/activate-license.md).

If you have problems with the licence (e.g. the full version is not recognized),
the page [Licence problems](../help/license-problems.md) will help.
