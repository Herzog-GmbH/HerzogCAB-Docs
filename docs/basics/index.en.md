# Basics

!!! info "Concept — The operating concepts that apply throughout Herzog CAB"

This chapter explains the operating concepts that you encounter again in **all** areas of
Herzog CAB — from the structure of the main window and the navigation
to the common structure of all calculation pages. The reference pages of the
individual modules link to these basics instead of repeating them.

If you are using Herzog CAB for the first time, it is best to read
[Interface overview](interface.md) and
[Navigating the app](navigation.md) first.
