# Geführte Touren

!!! info "Konzept — Interaktive Rundgänge, die Bediener direkt im Programm einlernen"

Herzog CAB enthält eingebaute, interaktive **Touren**, die neue Bediener
Schritt für Schritt durch einzelne Funktionsbereiche führen. Die Hinweise
erscheinen als Sprechblasen direkt im Programm und markieren das jeweilige
Bedienelement.

## Eine Tour starten

=== "Über das Menü"

    Wählen Sie *Hilfe > Geführte Touren…*. Es öffnet sich der Dialog
    **Geführte Touren** mit einer Karte je Thema. Klicken Sie auf die
    **Start-Schaltfläche** (▶) unter der gewünschten Karte; **Schließen**
    verlässt den Dialog ohne Tour.

=== "Mit F1"

    Drücken Sie ++f1++, während Sie sich in einem Funktionsbereich
    befinden: Die Tour dieses Bereichs startet direkt. Steht der Fokus
    (oder der Mauszeiger) in der Navigation, startet stattdessen die
    **Navigations-Tour**.

## Verfügbare Touren

| Tour | Inhalt |
|---|---|
| **Navigation** | Hauptnavigation und Struktur von Herzog CAB kennenlernen. |
| **Designer** | Flechtdesigns erstellen, Farben anpassen, Draufsicht nutzen — siehe [Designer](../designer/index.md). |
| **Druck Editor** | Druckvorlagen gestalten und Elemente platzieren — siehe [Druck-Editor](../print-templates/editor.md). |
| **Berechnung** | Flechtparameter berechnen und Ergebnisse verstehen — am Beispiel [Flechtwinkel](../calculations/product/braid-angle.md). |
| **Farbdatenbank** | Farben verwalten, Paletten anlegen — siehe [Farben](../master-data/colors.md). |
| **Spulendatenbank** | Spulen anlegen und Maschinentypen zuordnen — siehe [Spulen](../master-data/bobbins.md). |
| **Materialdatenbank** | Materialien anlegen und pflegen — siehe [Materialien](../master-data/materials.md). |
| **Kundendatenbank** | Kunden anlegen und importieren — siehe [Kunden](../master-data/customers.md). |
| **Flechtmaschinen** | Eigene Flechtmaschinen mit Stammdaten und Dokumenten verwalten — siehe [Flechtmaschinen](../master-data/braiding-machines.md). |
| **Auftragseditor** | Einen vollständigen Auftrag erfassen — siehe [Flechtauftrag](../orders/braiding-order.md). |

Beim Start einer Tour wechselt Herzog CAB automatisch in den passenden
Bereich.

## Bedienung während der Tour

In jeder Sprechblase finden Sie:

* **Weiter** — zum nächsten Schritt (im letzten Schritt heißt die
  Schaltfläche **Schließen**).
* **Zurück** — zum vorherigen Schritt.
* **Überspringen** — beendet die Tour sofort.
* Die **Schrittanzeige** „Schritt X von Y" zeigt den Fortschritt.

!!! tip "Touren zum Einlernen nutzen"
    Lassen Sie neue Bediener die Tour des jeweiligen Moduls einmal komplett
    durchlaufen — das spart Erklärzeit und vermeidet Bedienfehler.
