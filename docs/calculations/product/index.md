# Produkt

!!! abstract "Referenz — Übersicht der Berechnungen rund um das fertige Produkt"

Berechnungen rund um das fertige Produkt – Flechtwinkel, Geflechtsdichte,
Durchmesser, Länge, Gewicht und das zweilagige Kern-Mantel-Produkt. Für
rohr-/schlauchförmige Geflechte gibt es die eigene Untergruppe
[Hohlgeflecht](../tubular-braid/index.md).
