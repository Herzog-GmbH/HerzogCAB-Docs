# Production

!!! abstract "Reference — Overview of the calculations relating to manufacturing"

Calculations relating to manufacturing on the braiding machine – speed,
installation dimensions, runtime per bobbin set and the change gears of the
rubber feed device. In the app, this group is located under **Calculations →
Production**.

!!! info "Number of bobbin winding machines is now under Winding"
