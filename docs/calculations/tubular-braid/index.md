# Hohlgeflecht

Berechnungen für schlauch- bzw. rohrförmige Geflechte (Hohlgeflecht):
Klöppelzahl, Durchmesser, Materialbreite und Bedeckung. In der App liegt diese
Gruppe unter **Berechnungen → Produkt → Hohlgeflecht**. Alle vier
Berechnungen teilen dasselbe geometrische Modell und dieselbe live
mitlaufende Schema-Skizze – Sie können also z. B. mit der Klöppelanzahl
starten und später über [Durchmesser](tube-diameter.md) oder
[Bedeckung](tube-cover.md) dieselbe Konfiguration aus einem anderen
Blickwinkel prüfen.
