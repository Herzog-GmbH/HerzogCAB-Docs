# Hollow braid

!!! abstract "Reference — Overview of the hollow braid calculations"

Calculations for hose-shaped or tubular braids (hollow braid):
number of carriers, diameter, material width and covering. In the app, this
group is located under **Calculations → Product → Hollow braid**. All four
calculations share the same geometric model and the same schematic sketch
that updates live – so you can, for example, start with the number of carriers
and later check the same configuration from a different angle via [Diameter](tube-diameter.md) or
[Covering](tube-cover.md).
