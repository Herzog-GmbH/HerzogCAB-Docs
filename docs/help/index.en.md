# Help and FAQ

!!! question "Troubleshooting — Starting point for troubleshooting"

Here you will find solutions to the most common problems with licence, sign-in,
printing and updates. If this page does not help you, read
[Contact support](support.md).

<div class="grid cards" markdown>

- :material-key-alert: __Licence problems__

    ---

    Herzog CAB does not start, finds no free seat in the customer account or
    reports that no valid licence was found – account, dongle,
    software licence or network.

    [:octicons-arrow-right-24: View solutions](license-problems.md)

- :material-account-lock: __Sign-in problems__

    ---

    Wrong password, authenticator app code rejected, user
    deactivated, all seats taken – as well as problems signing in
    with Microsoft Entra ID.

    [:octicons-arrow-right-24: View solutions](login-problems.md)

- :material-printer-alert: __Printing problems__

    ---

    The printer is not found, or the print preview shows wrong or
    empty data.

    [:octicons-arrow-right-24: View solutions](print-problems.md)

- :material-cloud-alert: __Update errors__

    ---

    The update dialog does not appear, or the maintenance tool aborts during
    installation.

    [:octicons-arrow-right-24: View solutions](update-errors.md)

- :material-alert-circle-outline: __Known limitations__

    ---

    Limits of Herzog CAB that are not errors but intended –
    for reference before you open a ticket.

    [:octicons-arrow-right-24: View overview](limitations.md)

- :material-face-agent: __Contact support__

    ---

    If these pages don't help: email, phone and what you should have ready
    for a quick answer.

    [:octicons-arrow-right-24: View contact](support.md)

</div>
