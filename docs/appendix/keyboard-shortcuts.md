# Tastenkürzel

!!! abstract "Referenz — Alle Tastenkürzel im Überblick"

## Global

Diese Tasten wirken unabhängig davon, welcher Programmbereich gerade
geöffnet ist.

| Taste | Wirkung |
|---|---|
| ++ctrl+p++ | Drucken |
| ++f1++ | Hilfe zur aktuellen Seite (siehe [Hilfe-Tasten](#hilfe-tasten) unten) |

## Berechnungsseiten

| Taste | Wirkung |
|---|---|
| ++enter++ | Löst die Schaltfläche **Berechnen** aus |

## Designer

| Taste | Wirkung |
|---|---|
| ++ctrl+n++ | Neues Design |
| ++ctrl+o++ | Design öffnen |
| ++ctrl+s++ | Design speichern |
| ++ctrl+p++ | Design drucken |
| ++ctrl+z++ | Rückgängig |
| ++ctrl+y++ | Wiederholen |

## Design-Bibliothek

Wirkt auf die gerade markierten Designs bzw. Ordner.

| Taste | Wirkung |
|---|---|
| ++ctrl+c++ | Kopieren |
| ++ctrl+x++ | Ausschneiden |
| ++ctrl+v++ | Einfügen |
| ++delete++ | Löschen |

## Druck-Editor

Wirkt auf das gerade markierte Element der Druckvorlage.

| Taste | Wirkung |
|---|---|
| ++ctrl+c++ | Element kopieren |
| ++ctrl+v++ | Element einfügen |
| ++delete++ | Element löschen |

## Hilfe-Tasten

| Taste | Wirkung |
|---|---|
| ++f1++ | Startet die **Guided Tour** des Bereichs, in dem Sie sich gerade befinden. |
