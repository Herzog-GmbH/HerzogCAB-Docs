# Keyboard shortcuts

!!! abstract "Reference — All keyboard shortcuts at a glance"

## Global

These keys work regardless of which program area is currently
open.

| Key | Effect |
|---|---|
| ++ctrl+p++ | Print |
| ++f1++ | Matching page of this manual (see [Help keys](#hilfe-tasten) below) |
| ++shift+f1++ | Guided tour of the current page |

## Calculation pages { #berechnungsseiten }

| Key | Effect |
|---|---|
| ++enter++ | Triggers the **Calculate** button |

## Designer

| Key | Effect |
|---|---|
| ++ctrl+n++ | New design |
| ++ctrl+o++ | Open design |
| ++ctrl+s++ | Save design |
| ++ctrl+p++ | Print design |
| ++ctrl+z++ | Undo |
| ++ctrl+y++ | Redo |

## Design library { #designbibliothek }

Applies to the currently selected designs or folders.

| Key | Effect |
|---|---|
| ++ctrl+c++ | Copy |
| ++ctrl+x++ | Cut |
| ++ctrl+v++ | Paste |
| ++delete++ | Delete |

## Print editor { #druck-editor }

Applies to the currently selected element of the print template.

| Key | Effect |
|---|---|
| ++ctrl+c++ | Copy element |
| ++ctrl+v++ | Paste element |
| ++delete++ | Delete element |

## Help keys { #hilfe-tasten }

| Key | Effect |
|---|---|
| ++f1++ | Opens the **page of this manual** in the default browser that matches the page or dialog that has the focus (otherwise the open page). If there is no dedicated manual page, the manual's home page opens. Also works in dialogs; equivalent to the menu *Help → Manual*. |
| ++shift+f1++ | Starts the **tour** of the area you are currently in (focus in the navigation: navigation tour). |
| ++cmd+question++ / ++fn+f1++ | macOS: same as ++f1++. |

In addition, you can open any available tour manually via the menu *Help > Guided Tours…*,
regardless of where you currently are – see
[Guided Tours](../basics/guided-tour.md).

!!! info "No substitute for this manual"
    The tour briefly shows you the most important controls directly in the
    program. For detailed explanations of each field, press
    ++f1++ to open the matching reference page in this manual.
