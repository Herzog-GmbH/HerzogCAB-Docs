# Design, calculate<br><span class="grad">and produce braids.</span>

<p class="hero-sub">
The complete user manual for the calculation and design software
for Herzog braiding machines — from installation through day-to-day
operation to administration in the plant.
</p>

**Herzog CAB** is the calculation and design software from Herzog GmbH
for braiding machines. You use it to calculate material, product, production
and winding parameters, create braid designs, manage braiding and
winding orders, plan your Machine Fleet and production hall, and print finished
production documents. Since version 2.0, Herzog CAB is available as a
**desktop app** for Windows and macOS and as a **web app** in the browser —
both with a shared customer account.

This manual is intended for **users** in the plant — operators,
production planning and administrators. It is divided into seven sections,
which you will find in the header bar at the top.

## New in version 2.0 { #neu-in-version-20 }

<div class="grid cards" markdown>

- :material-account-key-outline: __Customer account instead of dongle__

    ---

    Herzog CAB signs in to your company's customer account and draws its
    licence from the pool — one login for desktop app, web app and portal,
    with a second factor if you wish. Existing customers with a dongle change nothing.

    [:octicons-arrow-right-24: Customer account and invitation](setup/account.md)<br>
    [:octicons-arrow-right-24: Licence portal](portal/index.md)

- :material-web: __Herzog CAB Web__

    ---

    The complete program in the browser — orders, calculations, Designer with
    3D, machines, master data, Factory Planner and printing, also on a tablet.
    Free 30-day trial version, available on request from Herzog.

    [:octicons-arrow-right-24: Web app](web/index.md)

- :material-rotate-3d: __Real 3D view in the Designer__

    ---

    The **3D** switch shows the braid as a spatial model built from the
    carrier paths — for all six braid types, with material and
    covering.

    [:octicons-arrow-right-24: Views and 3D view](designer/view-3d.md)

- :material-cloud-upload-outline: __Cloud upload__

    ---

    The desktop app automatically uploads its workspace folder to the web app
    — orders, designs, machines and master data are always
    up to date there.

    [:octicons-arrow-right-24: Licence and cloud](admin/settings/license.md)

</div>
