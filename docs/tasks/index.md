# Aufgaben & Abläufe

!!! info "Konzept — Schritt-für-Schritt-Abläufe über mehrere Programmbereiche hinweg"

Die Seiten in diesem Kapitel führen Sie durch komplette Arbeitsabläufe — vom
ersten Klick bis zum fertigen Ergebnis. Jeder Ablauf verweist auf die
passenden Referenzseiten, auf denen alle Felder und Schaltflächen im Detail
erklärt sind. Wenn Sie ein einzelnes Feld nachschlagen möchten, nutzen Sie
direkt die Kapitel unter „Funktionen"; wenn Sie wissen möchten, *in welcher
Reihenfolge* Sie vorgehen, sind Sie hier richtig.

<div class="grid cards" markdown>

-   :material-clipboard-text:{ .lg .middle } **Vom Kundenauftrag zum Maschinenzettel**

    ---

    Kunde anlegen, Flechtauftrag ausfüllen, Berechnungen nutzen, drucken und
    die Maschine im Maschinenpark im Blick behalten — der Kernablauf von
    Herzog CAB.

    [:octicons-arrow-right-24: Zum Ablauf](order-to-machine-sheet.md)

-   :material-palette:{ .lg .middle } **Ein Design entwerfen und drucken**

    ---

    Vom leeren Designer über Geflechtart, Farben und Gangbahn-Animation bis
    zum gespeicherten und gedruckten Design.

    [:octicons-arrow-right-24: Zum Ablauf](design-from-scratch.md)

-   :material-rotate-right:{ .lg .middle } **Spulen für einen Flechtauftrag planen**

    ---

    Spulmaschinen-Stammdaten prüfen, einen Spulauftrag aus dem Flechtauftrag
    ableiten, Sollwerte berechnen und den Spulauftrag drucken.

    [:octicons-arrow-right-24: Zum Ablauf](plan-winding.md)

-   :material-floor-plan:{ .lg .middle } **Eine Produktionshalle aufbauen**

    ---

    Grundriss zeichnen, Belegung anlegen, Maschinen platzieren und das
    Ergebnis in der 3D-Hallenansicht kontrollieren.

    [:octicons-arrow-right-24: Zum Ablauf](build-hall.md)

-   :material-calculator-variant:{ .lg .middle } **Material richtig kalkulieren**

    ---

    Die typische Kalkulationskette: von den Material-Stammdaten über Feinheit
    und Materialdurchmesser bis zu Produktlänge und Produktgewicht.

    [:octicons-arrow-right-24: Zum Ablauf](material-calculation.md)

-   :material-printer:{ .lg .middle } **Eine Druckvorlage erstellen**

    ---

    Eigene Druckvorlage anlegen, Elemente und Platzhalter platzieren und die
    Vorlage im Auftrag verwenden.

    [:octicons-arrow-right-24: Zum Ablauf](create-print-template.md)

-   :material-account-multiple-plus:{ .lg .middle } **Benutzer und Rollen einrichten**

    ---

    Rollen festlegen und Benutzer anlegen — lokal oder per Microsoft Entra ID
    bzw. LDAP/Active Directory — und die Anmeldung testen.

    [:octicons-arrow-right-24: Zum Ablauf](setup-users.md)

</div>

!!! tip "So sind die Abläufe aufgebaut"
    Jede Seite beginnt mit den **Voraussetzungen** und einem
    **Ablaufdiagramm**, danach folgen die nummerierten Schritte. Am Ende
    steht, woran Sie den Erfolg erkennen — und wohin Sie sich wenden, wenn
    etwas nicht klappt.
