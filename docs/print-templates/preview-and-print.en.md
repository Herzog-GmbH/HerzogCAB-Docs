# Preview and print

!!! abstract "Reference — template preview in the editor and the actual printout"

## Live preview in the editor { #live-vorschau-im-editor }

The page canvas in the print editor is also the preview: it shows the
template true to the original in the selected **Paper size** and the selected
**Orientation** (portrait/landscape). Use the zoom controls at the top to adjust the
display size without changing the layout.

![Page canvas as a true-to-original preview of the template.](../assets/screenshots/print-templates/druck-editor.png)

## Set the page format { #seitenformat-einstellen }

On the right in the page settings, choose **Paper size**, **Orientation**
and **Page margin (mm)**. You extend multi-page templates with **Add
page**.

## Printing and PDF export { #drucken-und-pdf-export }

You do not trigger the actual printing in the editor, but in the place
the template is intended for (see **Usage**) — there it is filled with
the real data and shown in a print preview. From there
you print on a printer or output as **PDF**.

| Usage | Where you print |
|---|---|
| **Order** | Via **Print** in the [order](../orders/print.md). |
| **Design** | Via [Designer → Save and print](../designer/save-print.md). |
| **Calculation** | Via *File > Print…* (++ctrl+p++) with the calculation open. If there are several matching templates, you first choose which one to use. |

!!! tip "Test before series use"
    Print a new template once with real data (or as PDF) to check
    placement, page breaks and margins before you use it in
    production.
